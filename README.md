# Café Origen: análisis de ventas

Muestra de 12 registros de ventas y ejercicios iniciales de exploración con Node.js.

## Requisitos

- Node.js LTS

## Explorar los datos

Desde la raíz del proyecto, ejecuta:

```sh
node src/explorar.js
```

El script muestra el número de registros, el primero y el último, el producto del registro en la posición 4 y la tabla completa. El diccionario y las decisiones sobre casos borde están en [bitacora.md](./bitacora.md).
